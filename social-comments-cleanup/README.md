# Social Comments Cleanup

Набор Python-скриптов для удаления **собственных комментариев** из Instagram, LinkedIn и YouTube с помощью Playwright и установленного Google Chrome.

> Используйте инструменты только для своих аккаунтов и только для действий, на которые у вас есть право. Удаление комментариев может быть необратимым. Автоматизация может противоречить правилам конкретной платформы и привести к ограничениям аккаунта. Перед запуском проверьте актуальные условия использования Instagram, LinkedIn и Google/YouTube. Автор репозитория не связан с этими платформами.

## Состав

| Файл | Назначение |
|---|---|
| `instagram_delete_own_comments.py` | Удаление собственных комментариев через раздел «Ваша активность» Instagram |
| `linkedin_delete_own_comments_auto_v3.py` | Удаление собственных комментариев на странице активности LinkedIn |
| `youtube_delete_own_comments.py` | Удаление собственных комментариев через Google «Мои действия» |

## Требования

- Windows 10/11 или macOS (Intel или Apple Silicon).
- Python 3.10 или новее.
- Установленный Google Chrome.
- Доступ к соответствующему аккаунту.

Скрипты используют установленный Google Chrome, а не браузер, скачиваемый Playwright. Путь к Chrome определяется автоматически. Если Chrome установлен нестандартно, задайте переменную окружения `CHROME_PATH`.

## Установка

Откройте терминал в папке проекта.

### Windows (PowerShell или CMD)

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

### macOS (Terminal)

Установите Google Chrome и Python 3.10+, затем выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Если хотите установить Playwright отдельно, команда такая:

```bash
python -m pip install playwright
```

`requirements.txt` уже содержит Playwright, поэтому отдельная установка обычно не нужна.

### Если Chrome установлен не в стандартном месте

macOS (пример):

```bash
export CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

Windows PowerShell (пример):

```powershell
$env:CHROME_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

Укажите фактический путь к исполняемому файлу Chrome в своей системе.

## Запуск

Запускайте нужный скрипт отдельно из активированного виртуального окружения:

```bash
python instagram_delete_own_comments.py
```

```bash
python linkedin_delete_own_comments_auto_v3.py
```

```bash
python youtube_delete_own_comments.py
```

На macOS при необходимости используйте `python3` вместо `python`.

Для LinkedIn перед запуском откройте `linkedin_delete_own_comments_auto_v3.py` и укажите адрес страницы комментариев своего профиля в `COMMENTS_URL`. Сохраните структуру URL с путём `/recent-activity/comments/`. Поле `OWNER_NAME` можно оставить пустым; если заполнить его, укажите отображаемое имя своего аккаунта.

Скрипты создают отдельный постоянный профиль Chrome в папке проекта. При первом запуске войдите в нужный аккаунт вручную в открывшемся окне браузера. Не передавайте никому папки профилей: в них могут храниться активные сессии и cookies.

## Важные замечания

- Скрипты предназначены только для собственных комментариев. Не используйте их для доступа к чужим аккаунтам или удаления чужого контента.
- Перед массовым удалением рекомендуется проверить работу на небольшом количестве комментариев.
- Не закрывайте окно браузера во время выполнения.
- Если интерфейс платформы изменился, скрипт может перестать находить нужные элементы. Не запускайте массовое удаление, пока не проверите поведение вручную.
- Скрипты создают локальные журналы `*.jsonl` и отладочные каталоги со скриншотами/HTML. В них может оказаться текст комментариев, данные профиля или другая личная информация. Не публикуйте эти файлы.
- Не добавляйте в репозиторий cookies, данные браузерных профилей, пароли, токены, скриншоты личного кабинета или HTML-дампы.
- На macOS и Windows интерфейсы сайтов и доступность элементов могут отличаться. Кроссплатформенная поддержка путей к Chrome реализована, но каждый сценарий не был проверен на физическом Mac.
- Этот проект предоставляется «как есть», без гарантий. Пользователь самостоятельно отвечает за соблюдение законодательства и правил платформ.

## Приватность и безопасность

В опубликованных исходниках не должны находиться пароли, cookies, токены или персональные URL профилей. Авторизация выполняется вручную в локальном окне Chrome. Локальные профили браузера, журналы и отладочные материалы исключены через `.gitignore`.

Перед публикацией проверьте изменения:

```bash
git status --short
```

Убедитесь, что в коммиты не попали профили браузера, журналы, отладочные материалы и личные файлы.
